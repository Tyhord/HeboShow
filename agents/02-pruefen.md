# Prüfen

> This documentation has been fully generated by an AI.

## Befehle

```powershell
# Tests: Regeln, Arena, Tracking, kompletter Ablauf mit Fake-Kamera
.venv\Scripts\python -m pytest -q

# Lint
.venv\Scripts\python -m ruff check hebocon tests

# Import und Start ohne Fenster
.venv\Scripts\python -c "import hebocon.server; print('ok')"
.venv\Scripts\python -m hebocon --no-window --camera pfad\zu\video.mp4
```

Die Tests brauchen weder echtes Modell noch Kamera. Der Ablauf läuft zweimal: ohne Modell
und mit einem Fake-EdgeTAM. Auf Windows meldet pytest eine „access violation“ beim Import
von `av`; das ist nur der Faulthandler. `-p no:faulthandler` zeigt den echten Ausgang.

## Von Hand

Mit einem Testvideo oder echter Kamera:

1. Ecken anklicken (Leerbild kommt automatisch).
2. Neuer Kampf, beide Roboter bestätigen (Erkennung läuft automatisch).
3. Start, Hindernis, Power-up und Schrumpfen auslösen, einen Roboter rausfahren.
4. Bühne prüfen: Umrisse, HP-Balken, Effekte, Sperrgebiet, Siegerbanner.
