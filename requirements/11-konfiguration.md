# Konfiguration

> This documentation has been fully generated by an AI.

Jeder Wert lässt sich per Umgebungsvariable oder `.env` im Startordner setzen. Vorlage:
[`../.env.example`](../.env.example). Nach dem Ändern die App neu starten.

## Kamera und Anzeige

| Variable | Standard | Wirkung |
| --- | --- | --- |
| `HEBOCON_CAMERA` | `0` | Quelle, siehe [05-kamera-quellen.md](05-kamera-quellen.md) |
| `HEBOCON_CAMERA_WIDTH` | `1280` | Gewünschte Breite lokaler Kameras |
| `HEBOCON_CAMERA_HEIGHT` | `720` | Gewünschte Höhe lokaler Kameras |
| `HEBOCON_PORT` | `8765` | Port des lokalen Servers |
| `HEBOCON_DATA_DIR` | `data` | Ablage für Ecken und Leerbild |
| `HEBOCON_STAGE_FULLSCREEN` | `false` | Bühne im Vollbild öffnen |
| `HEBOCON_JPEG_QUALITY` | `80` | Bildqualität im Stream |
| `HEBOCON_STREAM_MAX_WIDTH` | `1280` | Breitere Bilder werden für den Stream verkleinert |
| `HEBOCON_INTRO_S` | `7.5` | Dauer des Intro-Videos vor jedem Kampf in Sekunden; `0` startet sofort ohne Intro, VS-Bildschirm und Countdown |

## Modell und Erkennung

| Variable | Standard | Wirkung |
| --- | --- | --- |
| `HEBOCON_MODEL_ID` | `yonigozlan/EdgeTAM-hf` | Hugging-Face-Modell |
| `HEBOCON_TORCH_THREADS` | `0` | CPU-Threads für Torch, 0 = Standard |
| `HEBOCON_WHITE_BACKGROUND` | `true` | Leerbild-ähnliche Pixel im Modellbild weiß machen; `false` bei Robotern in Arenafarbe |
| `HEBOCON_SEGMENT_ENABLED` | `false` | `true` = EdgeTAM verfeinert die Maske bei der Registrierung und prüft nebenher die Identitäten. Lohnt sich nur mit GPU; das Tracking selbst läuft immer ohne Modell. |
| `HEBOCON_ARENA_UNITS` | `1000` | Kantenlänge der entzerrten Arena |
| `HEBOCON_FOREGROUND_THRESHOLD` | `18` | Kleiner = empfindlicher, größer = weniger Rauschen |
| `HEBOCON_MIN_ROBOT_AREA_PX` | `400` | Kleinere Klumpen werden ignoriert |
